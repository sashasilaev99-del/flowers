# Интернет-магазин цветов «Букет» — портфолио-проект

Цветочная лавка: авторские букеты, монобукеты и композиции в шляпных коробках.
Одностраничный сайт-каталог с фильтрацией товаров по категориям на JavaScript, модальным окном с детальным составом и интерактивной корзиной.

## Что реализовано

- **HTML5** — семантическая вёрстка, доступность (aria-атрибуты, модальное окно с ловушкой фокуса `Focus Trap`).
- **CSS3** — CSS Grid, Flexbox, переменные, плавные переходы, адаптивная вёрстка под смартфоны и планшеты.
- **JavaScript** — динамический рендер каталога из массива данных (`data.js`), фильтрация по категориям без перезагрузки страницы, модальное окно товара, корзина с сохранением в `localStorage`, мобильное меню.
- **Адаптивность** — мобильные устройства, планшеты, десктоп.

## Как запустить локально

1. Склонируйте репозиторий или скачайте ZIP:

   ```bash
   git clone https://github.com/sashasilaev99-del/flowers.git
   cd flowers
   ```

2. Откройте `index.html` в браузере.

## Проверка на устройствах

DevTools → Device Toolbar (Ctrl+Shift+M):

- 375 × 667 — iPhone SE (одна колонка, гамбургер-меню)
- 768 × 1024 — iPad (две колонки)
- 1920 × 1080 — десктоп (три колонки)

Что проверяется: фильтры, открытие и закрытие модалки (крестик, клик по фону, Esc), счётчик корзины после перезагрузки страницы.
